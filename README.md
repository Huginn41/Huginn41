## 🚀 Проекты

### 🟢 [Tilda → VK Webhook](https://github.com/Huginn41/tilda-vk-webhook) — Production
Сервис уведомлений о заказах для действующего розничного магазина.
Работает на Railway с мая 2025 года без перебоев.

`FastAPI` `VK API` `Docker` `Railway`

---

### [Events Aggregator](https://github.com/Huginn41/event-aggregator)
REST API для агрегации мероприятий от внешнего провайдера.
Фоновая синхронизация, пагинация, регистрация билетов. Развёрнут в Kubernetes.

`FastAPI` `PostgreSQL` `SQLAlchemy async` `asyncpg` `Kubernetes` `pytest`

---

### [Микроблог — REST API](https://github.com/Huginn41/advanced_project_v1)
Корпоративный сервис микроблогов: подписки, лайки, медиафайлы.
Async ORM, Docker Compose + Nginx, интеграционные тесты на SQLite in-memory.

`FastAPI` `PostgreSQL` `SQLAlchemy 2` `Nginx` `pytest-asyncio`

---

### [Kinopoisk Telegram Bot](https://github.com/Huginn41/kinopoisk_bot)
Бот для поиска фильмов с FSM-диалогами, историей поиска и списком избранного.

`Python` `pyTelegramBotAPI` `FSM` `Peewee ORM` `SQLite`
